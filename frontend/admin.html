🔥 How to Set Someone as Super Admin in Firebase

To grant Super Admin access using Firebase Firestore:

  1. Open the Firebase Console and select your project.
  2. Go to Build > Firestore Database and click on the users collection.
  3. Select the document corresponding to the user's Auth UID (or email).
  4. Set or edit the field role (Type: string) to super_admin.
  5. Save changes. The account now has full Super Admin rights!

💡 Note: Existing Super Admins or Admins can also update any user's role directly using the role dropdown in the table below!
